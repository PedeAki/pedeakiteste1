# Plis Food Teste

Protótipo estático de um aplicativo de delivery inspirado em experiências como iFood, feito apenas para teste.

## O que o aplicativo simula

- Um agregador que alterna entre vários "sites" de delivery dentro da mesma interface.
- Uma barra de navegador interna com URLs fictícias para deixar claro que os sites são emulados.
- Cards de restaurantes/produtos, botão de adicionar e carrinho com total simulado.
- Aviso de protótipo: nenhum pedido real é enviado.

## Como executar localmente

Abra o arquivo `index.html` diretamente no navegador ou rode um servidor estático:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.
